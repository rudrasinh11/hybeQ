# HybeQ Chemicals

High-performance construction chemicals web application built with React, TypeScript, and Vite. Inspired by international architectural standards with interactive hero showcases, kinetic typography marquees, animated metric counters, and authentic product packaging.

## Features

- **Hero Showcase Carousel**: Custom stepped notch geometry with interactive lead form and authentic Hybeq product lineup.
- **Our Product Range**: Centered header, kinetic marquee text with scroll scrub, and animated counter metrics.
- **Client & Partner Marquees**: Dual opposite scrolling marquees with high-contrast logos.
- **Big Stats Section**: Animated numbers from 0 on scroll.
- **White Theme**: Architectural, crisp, modern styling.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
